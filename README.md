# Muscle Mirror｜看見每一下訓練

產品網站 + Build Day 原型（第一版：單側啞鈴二頭彎舉）。

- `/`（`index.html`）— 產品首頁：動態虛擬肌肉手臂、三種模擬視圖、訓練流程、示意紀錄卡、原則、Fable 角色。
- `/app.html` — 訓練 App（攝影機追蹤、虛擬手臂、組後比較、紀錄卡、回放、長期紀錄）。`?demo=1` 直接載入示範資料。

**看見動作 → 理解肌肉 → 發現變化 → 累積紀錄。**

## 這版做了什麼

1. 攝影機追蹤肩、肘、腕（MediaPipe Pose，裝置端），計算肘角與次數。
2. 二維虛擬手臂同步活動，三種視圖：肌肉（預期參與角色，標示「模擬」）、骨骼、力學（簡化外力矩）。
3. 組後比較前段與後段的活動幅度、節奏、手肘位移、軀幹晃動；少於 4 次顯示「本組不適合比較」。
4. 主觀用力（1–10）、預估剩餘次數、註記；產生一張訓練紀錄卡並儲存於瀏覽器 localStorage。
5. 回放比較：任選兩次動作並排慢速播放，時間軸可拖曳，附肘角曲線與差異表。
6. 長期紀錄：相同動作／側／重量優先比較；肌肉地圖只顯示「本週安排過訓練」的組數。
7. Fable（選用）：只讀結構化數據產生組後摘要與回答問題。沒有憑證時自動改用本機規則摘要並標示來源。

原始影片預設不保存；勾選「保留本組原始影片」時，影片只留在頁面記憶體，組後可下載。示範資料明確標示為「合成，非實測」。

長期比較時會檢查拍攝距離（校準時的上臂長度比例）、站姿角度與節奏是否相近，不相近就標示「比較僅供參考」。

## 虛擬肌肉模型（模擬）

`public/js/arm.js` 以量測到的肘角驅動分層解剖插圖：三角肌、肱二頭肌（肌腹隨屈曲縮短、增厚，遠端肌腱跨過肘窩）、肱肌、肱橈肌、肱三頭肌、前臂屈／伸肌群；下層為肱骨、尺骨（含肘突）、橈骨。肌肉顏色深淺代表動作模型中的「預期參與程度」，依抬起／停留／放下切換主動肌、協同肌、拮抗肌角色，並以引線標示中英文名稱。力學視圖是自由體圖：支點、m·g 向量、水平力臂 d = L·cos φ、力矩弧與「外力矩 vs 肘角」曲線。畫面一律有「模擬 SIMULATION」標記。

## 執行

```bash
cd muscle-mirror
npm install
npm start          # http://localhost:5173
```

攝影機需要 `localhost` 或 HTTPS。若要啟用 Fable 摘要，先設定憑證：

```bash
export ANTHROPIC_API_KEY=sk-ant-...
npm start
```

預設模型 `claude-fable-5-1`（可用 `MM_MODEL` 環境變數改）。已啟用伺服器端 refusal fallback。

## 部署為靜態網站

`public/` 可直接放到 GitHub Pages、Netlify 或 Vercel（攝影機需要 HTTPS）。沒有後端時 `/api/*` 會失敗，App 自動改用本機規則摘要並在來源標籤說明；其餘功能不受影響。

## 測試

```bash
npm test   # 以合成的肩／肘／腕軌跡驗證次數分割、部分動作排除、追蹤品質門檻與手肘位移
```

## 兩分鐘展示流程

1. 開啟攝影機 → 姿態校準（手臂自然下垂 3 秒）→ 開始本組。
2. 做 8–10 次彎舉；最後幾下刻意放慢、縮小幅度。
3. 結束本組 → 看前段／後段比較 → 填吃力程度並註記「後段刻意放慢」→ 儲存。
4. 紀錄卡上點「回放 2 vs 9」→ 並排播放。
5. 沒有攝影機時，「載入示範資料」可走完整流程（會標示為示範）。

## 檔案

- `server.js` — 靜態伺服器 + `/api/summary`、`/api/ask`（Anthropic SDK）
- `public/js/pose.js` — MediaPipe PoseLandmarker 封裝
- `public/js/engine.js` — 肘角、階段、次數分割、每次動作指標、追蹤品質
- `public/index.html` + `public/js/landing.js` — 產品首頁與動態示意
- `public/app.html` — 訓練 App
- `public/js/arm.js` — 分層解剖虛擬手臂（肌肉／骨骼／力學）
- `public/js/analysis.js` — 即時提示、前後段比較、觀察、本機摘要、示範資料
- `public/js/replay.js` — 並排回放與曲線
- `public/js/store.js` — localStorage
- `public/js/app.js` — UI 流程（含選用的原始影片錄製）
- `test/engine.test.mjs` — 動作引擎單元測試
